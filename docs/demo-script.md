# Demo video script (1 minute 55 seconds)

The rules say the video must be **under 2 minutes** (judges can stop at 2:00), must show the app actually running, must be in **English**, and must not use copyrighted music. Upload it publicly to YouTube or Vimeo.

## Before recording

- Start the app with Foundry and Fabric on. The badges at the top should say **Foundry on** and **Fabric on**.
- Record at 1600 × 900 or larger, so overlay text is readable.
- Open these links in separate tabs. Use the port your app runs on (8010 locally, or the Azure URL):
  - **A (opening goal):** `/?scenario=comeback&t=400&speed=3`
  - **B (winner, then the agent):** `/?scenario=comeback&t=4105&speed=3`
  - **C (recap):** `/?scenario=comeback&t=5690&speed=5`
- Have a KQL query ready in Fabric (from `docs/fabric.md`), e.g. shots and goals by team.
- Add English subtitles whenever Spanish or Swahili text is on screen.

## Script

| Time | On screen | Voice-over |
|---|---|---|
| 0:00–0:10 | Tab A, split screen, match playing | "Football is more than the scoreline. FootieManager turns a live match into intelligence that explains itself, and shows every fan their own version of it." |
| 0:10–0:22 | Point at the five stage chips, then the pitch | "Every match is synthetic, generated by our own engine with player tracking. One pipeline: ingest, interpret, explain, render, personalise." |
| 0:22–0:50 | The goal lands on both sides. Wait for the **AI** badge, then click **Sources** in the left feed | "Same goal, two viewers. Left: an analyst, with xG, shot speed and how the move was built. Right: a Riverside fan, in Spanish, told it's bad news. Both get the why, written by Microsoft Foundry from computed facts only. Sources shows exactly what the AI was given." |
| 0:50–1:05 | Viewer B → Player focus → P. Dembe. Sprint tags appear on the pitch | "Player focus follows one player all match: sprints, distance and passes, tagged on the pitch as they happen." |
| 1:05–1:30 | Tab B. After the 67' goal, pause and type in Ask the match: "How did Riverside turn this around after half-time?" Hold on the answer and its steps | "Ask the match is an agent on Foundry. It decides which tools to call on the live match (trends, key moments, stats), shows every step, and cites the moments it used." |
| 1:30–1:42 | Cut to the KQL query in Fabric | "Every event also streams into Microsoft Fabric, so analysts can query the match live." |
| 1:42–1:55 | Tab C: full-time recap card | "Automatic recaps, in any language, ready for studio, broadcast or streaming. FootieManager: built on Microsoft Foundry, Fabric and GitHub." |

## Tips

- AI text appears about a second after the template text, so pause briefly before moving on.
- If the agent answer is slow, cut the wait out in editing.
- Rehearse once with a timer. If you're over 1:55, shorten the player-focus segment first.
