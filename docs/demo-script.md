# Demo video script (1 minute 55 seconds)

The rules say the video must be **under 2 minutes** (judges can stop at 2:00), must show the app actually running, must be in **English**, and must not use copyrighted music. Upload it publicly to YouTube or Vimeo.

## Before recording

- Start the app with Foundry and Fabric on. The badges at the top should say **Foundry on** and **Fabric on**.
- Record at 1600 × 900 or larger, so overlay text is readable.
- Open these links in separate tabs. Use the live Azure app (https://footiemanager.lemonisland-55346052.eastus2.azurecontainerapps.io) or your local one (port 8010):
  - **A (opening goal):** `/?scenario=comeback&t=400&speed=3`
  - **B (winner, then the agent):** `/?scenario=comeback&t=4105&speed=3`
  - **C (recap):** `/?scenario=comeback&t=5690&speed=5`
- Have a KQL query ready in Fabric (from `docs/fabric.md`), e.g. shots and goals by team.
- Add English subtitles whenever Spanish or Swahili text is on screen.

## Tips

- AI text appears about a second after the template text, so pause briefly before moving on.
- If the agent answer is slow, cut the wait out in editing.
- Rehearse once with a timer. If you're over 1:55, shorten the player-focus segment first.
